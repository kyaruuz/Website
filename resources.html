01 / PREVENTION

Seven habits for safe browsing

Small choices made consistently can reduce the chance of malware infection and account compromise.

  1. Keep everything updated. Turn on automatic updates for your operating system, browser, and apps.
  2. Use trusted security software. Keep built-in protection such as Windows Security on, and run scans regularly.
  3. Download only from official sources. Use the publisher’s own site or an official app store.
  4. Check the address before you sign in. Read the real domain and type it yourself when unsure.
  5. Use strong, unique passwords with multi-factor authentication. A password manager makes this practical.
  6. Think before you click. Do not open unexpected attachments or links, even from friends, without confirming.
  7. Back up important files. Keep a copy on a separate drive or cloud storage so ransomware cannot hold it hostage.

03 / INCIDENT RESPONSE

If you think your device is infected

  1. Disconnect. Turn off Wi-Fi or unplug the network cable so malware cannot spread or send data out.
  2. Scan. Run a full scan with your security software, and remove anything it finds.
  3. Change passwords. Use a different, clean device to change passwords for important accounts.
  4. Restore if needed. If the problem remains, reset the device and recover files from your backup.
  5. Report and learn. Tell your school IT office, and note how it happened so it does not repeat.
