Read the address, not just the padlock.

A secure-looking page is not automatically trustworthy. Learn to identify the real website before sharing information.

The real website is whatever comes right before the first single slash. Compare these two addresses. Both start with https and both show a padlock.

✓ Genuine example
https://google.com/search

The site name ends at google.com. Everything after that is just a page on that site.

! Fake example
https://google.com.secure-login.example/verify

The real site is secure-login.example. The word “google” is only a decoy placed in front of it.

Remember: a padlock means the connection is encrypted. It does not prove that the website is honest.
